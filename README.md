# 📱 Кабинет пациента — Telegram Mini App

Один статический файл `index.html`. Ни сервера, ни базы, ни сборки:
данные кабинета (проекция `PatientView` с белым списком полей) врач отправляет
из МирМеда в URL-фрагменте кнопки — хостинг статики их **не видит**
(фрагмент `#…` не отправляется на сервер). После первого открытия кабинет
кэшируется в телефоне пациента и работает офлайн.

## Что умеет пациент

- видеть ближайший визит (+ «✅ Приду / 🔁 Перенести» — перенос предлагает
  свободные слоты в чате), план лечения, назначения, рекомендации, динамику шкал;
- заполнить PHQ-9 / GAD-7 — результат сразу в карте (раздел «Шкалы», EWMA);
  на пункте 9 PHQ-9 мгновенно показывается кризисный экран с телефонами;
- чек-ин настроения (5 смайлов + заметка) — попадает во «Входящие» врача,
  заметка проходит детектор красных флагов;
- «Помощь сейчас»: телефоны клиники, 103/112, честная надпись про не-экстренность.

## Как развернуть (один раз, ~10 минут)

1. Положите `index.html` на любой HTTPS-хостинг статики. Проще всего —
   GitHub Pages: отдельный **публичный** репозиторий (в файле нет никаких
   данных пациентов — это просто интерфейс), Settings → Pages → Deploy from
   branch. Получите адрес вида `https://<user>.github.io/<repo>/`.
2. В МирМеде: раздел **«Связь» → Каналы → 📱 Кабинет пациента** — вставьте
   этот адрес и нажмите 💾.
3. Готово. В карте пациента → Чат Telegram → «📱 Личный кабинет → Отправить».
   Пациент получает постоянную кнопку «📱 Мой кабинет» под полем ввода.

BotFather не нужен: кнопка кабинета — обычная web_app-кнопка клавиатуры.
(Опционально можно через @BotFather → Bot Settings → Menu Button указать тот же
адрес, чтобы кабинет открывался и из меню бота — но тогда данные придут только
из кэша, без свежего обновления.)

## Обновление данных

Кнопка «Отправить» шлёт свежую проекцию. Пациент открывает кабинет по новой
кнопке → данные обновились и перезаписали кэш. Старые сообщения с кнопкой
продолжают открывать кабинет (покажут кэш).

## Границы данных (важно)

- В кабинет попадает только `PatientView` (`src/modules/patient-portal.js`):
  белый список полей + `assertNoLeak` + 21 тест герметичности.
  Диагноз по умолчанию выключен; сырые ответы шкал, red flags, заметки врача
  не могут попасть по построению.
- Трафик бота у Telegram **не** end-to-end зашифрован (E2E только в «секретных
  чатах» между людьми): серверы Telegram технически видят содержимое — как и
  весь остальной канал бота. Именно поэтому белый список и выключенный
  диагноз — не перестраховка, а граница.
